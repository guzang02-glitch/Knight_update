# 기사의 여행 (Knight's Journey)

L자 점프로 들판을 꽃밭으로 바꾸는 한붓그리기 퍼즐. 체스 나이트 이동(기사의 여행 문제)을 바탕으로, 바위로 경로를 줄이고 정답을 1개로 고정한 모바일 세로 화면용 웹 게임입니다.

## 실행

빌드 과정이 없는 단일 HTML입니다. `index.html`을 브라우저로 열거나, 아무 정적 서버로 이 폴더를 띄우면 됩니다.

```bash
npx serve .
```

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 게임 전체 (StageTable, StringTable 포함) |
| `img/` | 게임에서 쓰는 그림 |
| `assets*/`, `img-*/` | 그림 원본, 이전 화풍 버전 |
| `docs/` | 시스템 기획서, 레벨 디자인 기획서 (MD) |
| `tools/` | 레벨 디자인 스크립트 (스테이지 seed 선정, 단일 해 검증) |

## 모드

- **스테이지**: 50개, 보드 4×4 → 8×8. 힌트는 기본 5개, 첫 클리어 +1, 0개일 때 광고 시청 +1.
- **일일 퍼즐**: 날짜로 생성되는 하루 3개(쉬움 5×5, 보통 6×6, 어려움 7×7), 모두 정답 1개. 일일 전용 힌트 5개가 매일 리셋됩니다.
- **랭킹**: 일일 퍼즐 첫 클리어 기록으로 순위를 매깁니다. 힌트를 적게 쓴 순 → 클리어 시간이 짧은 순.
  claude.ai에서 열면 모든 플레이어의 순위가 실시간으로 갱신되고, 그 밖의 환경(로컬, GitHub Pages)에서는 이 기기 기록만 표시됩니다.
